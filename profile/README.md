> **Documentation should belong to the people who build it.**
>
> Founded by **[Wildan N](https://wildan.dev)** - DocuBook exists to make documentation open, portable, and developer-first—giving developers a better way to create, manage, and publish the knowledge behind their software.

### DocuBook Editor - [Editor](https://github.com/DocuBook/editor)
Write and manage documentation with a powerful WYSIWYG + Markdown editing experience, local content, AI assistance, and Git integration.

### DocuBook Flame - [Flame](https://github.com/DocuBook/docubook)
Turn Markdown documentation into fast, static HTML sites that can be deployed anywhere without a server.

> **Author with Editor. Publish with Flame.**
